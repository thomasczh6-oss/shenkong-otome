# 乙游调研报告：以《恋与深空》为标杆的移动端乙游设计

更新日期：2026-10-27。配合《深与空恋》Godot 原型使用，所有数据均来自公开报道与第三方估算，口径不一处已注明。

## 1. 市场概况

- **规模**：2025 中国游戏产业年会的女性向游戏报告称 2024 年国内女性向游戏市场 80 亿元，同比 +124.1%，远高于行业平均（虎嗅）。娱乐资本论认为 2024 年《恋与深空》《世界之外》《如鸢》三款新作把"国乙"推到约百亿规模；2025 年整体平淡，格局从"一超多强"变成"一超多弱"（36 氪）。
- **用户盘子**：中国女性游戏用户 2019 年突破 3 亿，占游戏用户 46.2%（澎湃）。Sensor Tower 统计 2023 年 1–8 月全球"女性青睐手游"收入超 112 亿美元。
- **头部**：《恋与深空》2024 年估算国内约 50 亿元、海外约 10 亿元（FoxData 估算）；叠纸 2024 年收入同比增长近 5 倍，出现单月破 10 亿元（澎湃）。Sensor Tower 口径：上线一年全球累计 4 亿美元，海外占 36%；维基百科引用口径：2025 年 3 月双端累计 5 亿美元，约 40% 来自海外；otome.com 表格给出 2024-10 至 2025-09 每月 5,600 万–9,860 万美元，中国占 70%–89%。2025 年国内每月流水仍稳定过亿（36 氪）。全球注册用户 2025 年初突破 5,000 万。
- **奖项与口碑**：2025 Gamescom 最佳移动游戏（首个获此奖的乙游）、GameSpot 2025 年度最佳之一、RPGFan 81 分。
- **2025 年其他产品**：《光与夜之恋》最稳，多月 iOS 畅销 TOP2，11 月 TOP1（游戏日报估算）；《如鸢》文案争议后转低调，流水有时冲上 1 亿；《世界之外》经历涨价争议与制作人离职，10 月流水仅 2,316 万元；新品《夜幕之下》二测预约超 100 万，3D 新作 Code Sol 关注度高但有抄袭争议。

**结论**：品类已经从小众变成百亿级赛道，但高度集中在一家；核心用户被反复教育、对运营和内容信任极为敏感，新品进入节奏慢，机会在于"情绪价值 + 尊重女性玩家 + 符合当下审美"的产品。

## 2. 《恋与深空》拆解

**世界观与角色**：2034 年临空市"深空隧道"打开，异星"漫宿者"入侵；玩家是拥有"共鸣"Evol 的深空猎人（可改名、捏脸、选声线，第一人称叙事）。男主：沈星回（光，猎人搭档）、黎深（冰，心外科医生、青梅竹马）、祁煜（火，画家、人鱼）、秦彻（能量，2.0 加入的反派首领）、夏以昼（重力，3.0 加入的养兄）。6.0（2026-07）宣布第六位男主 Valko，8 天后因玩家反弹取消，官方承诺不再加人。

**核心循环**：主线（视觉小说 + 全配音 3D 过场）→ ARPG 战斗（普攻 / 主动技 / 共鸣技 / 誓约技，地面红色预警格提示敌人攻击范围，破盾后增伤，共鸣槽满后与搭档放联合技，可自动战斗）→ 许愿抽"思念"（卡）→ 思念升级、芯核（配件）、日冕对与星谱（按颜色匹配战场）→ 亲密度（好感）→ 日常陪伴（短信、电话、朋友圈"瞬间"、猫猫卡牌、抓娃娃、拍照馆、真实时间的学习 / 运动陪伴，3.0 加生理期记录，5.0 加可装修的家园）。

**抽卡数值**（wiki.gg Wish 词条）：

| 项目 | 数值 |
| --- | --- |
| 5★ 基础概率 | 1% |
| 4★ 基础概率 | 7% |
| 5★ 软保底 | 60 抽后每抽 +10% |
| 5★ 硬保底 | 70 抽必出 |
| 4★ 保底 | 10 抽必出 |
| 限定池 UP | 上一个 5★ 非 UP 则下一个必为 UP（大保底跨同类型卡池继承） |
| 多人池 | "精准许愿"：3 选 1，歪了得许愿点，下一个 5★ 必为所选；3 张以上先选 3 张，下一个 5★ 75% 落在其中 |
| 货币 | 许愿券 1 张 / 抽；不足时钻石 150 / 抽 |
| 常驻池 | "星空回响"，只用常驻券 |

**商业化**：限定卡池（限定套每年一次，稀缺感强）、周年与节日活动、服饰饰品、月卡礼包；线下 IP 变现很重（罗森联动、天猫旗舰店双 11 玩具榜第一、生日应援）。2.0 加入肉鸽玩法"混沌深网"，走"以肝代氪"路线照顾非重氪玩家。重氪玩家月消费可达 7,000–10,000 元（Active Faults 报道）。

**技术与美术**：Unity 3D，真人 3D 采集（50 余台相机阵列、300fps 表演捕捉）、布料模拟，每位男主设计约两年；包体超过 10GB（3.3 版超过 16GB）。版本节奏约半年一个大版本（2.0 2024-07、3.0 2024-12、4.0 2025-07、5.0 2025-12、6.0 2026-07），主线约一年一章。

**争议（都是设计教训）**：卡池内容与 PV 不符；限定思念强度差 30% 引发黑猫集体投诉（558 件）；角色资源分配不均导致"停氪维权"；女主正脸与"男团舞"卡池被核心用户批 OOC；账号被盗潮；Valko 事件。

## 3. 同类对比

| 产品 | 厂商 / 年份 | 玩法骨架 | 特点与 2025 状态 |
| --- | --- | --- | --- |
| 恋与制作人 | 叠纸 2017 | 2D 卡牌 + 剧情 | 打开国内乙游市场，欧美版 2023 年 3 月前美国收入超 1,000 万美元 |
| 未定事件簿 | 米哈游 2020 | 律政推理 + 卡牌 | 职业线强；2025 年声量下降 |
| 时空中的绘旅人 | 网易 2020 | 多路线多结局 + 配队战斗 | 最接近"原教旨"日系乙游，对普通玩家不够友好 |
| 光与夜之恋 | 腾讯 2021 | 卡牌 + 事业 / 权力线 | 2025 年最稳，多月 TOP2，11 月 TOP1 |
| 世界之外 | 网易 2024 | 剧本杀式叙事 | 用户偏轻氪，剧情难转化为付费；2025 涨价争议后下滑 |
| 如鸢（代号鸢） | 灵犀互娱 2024 | 卡牌策略 + 女强 | 多角色情感线提升留存；文案争议后低调 |
| 恋与深空 | 叠纸 2024 | 3D 视觉小说 + ARPG + 日常陪伴 | 一超；日本互动叙事类收入第一（2024 年 1–9 月近 3,000 万美元） |
| 日本系 | Otomate 等 | 买断制 / 文字 AVG | 自《安琪莉可》(1994) 起，2015 年后受偶像养成冲击，大制作断档，给了国产 3D 乙游空间 |

**趋势**：从"纯恋爱"走向"多元角色宇宙"（事业、权力、群像）；玩家反感"霸总 / 慕强 / 养成式"，要求情感平等与"允许脆弱"的男主；原教旨日系画风难以扩圈，韩系或写实 3D 更易破圈；增长空间在"现充用户"和泛用户，而不是已被反复开发的核心二次元用户。

## 4. 用户画像

- **基本盘**：18–35 岁女性（otome.com）；国内以 90 / 00 后受教育女性为主，学生与白领，有真实消费力，60% 以上单身（虎嗅）。
- **三层结构**（36 氪）：核心"纯血二次元"（忠诚、爱发声、抱团，容易造成流水剧烈波动）；"现充用户"（姐姐、妈妈群体，不追社区节奏、喜欢就付费，是《恋与深空》抗风险的主因）；尚未激活的泛用户。
- **诉求**：可控、无风险的亲密关系，"情感主权"，角色是平等的伴侣而非仰视对象；偏好标签如"阳光小奶狗""美强惨""白切黑"；对战斗兴趣有限，更看重战斗后的奖励与恋爱体验，因此战斗必须可自动、可跳过。
- **行为**：高参与度社群（生日应援、周边"秒切"、超话），一边吐槽运营一边一致对外；对画面、剧情、玩法、音乐、人设任何一项都可能不满；对"货不对版""涨价""资源不均"零容忍。
- **付费**：主要花在限定卡池、服饰、月卡；重氪与轻氪分层明显，需要同时给"肝"和"氪"两条路。

## 5. 设计落地：映射到《深与空恋》原型

| 《恋与深空》系统 | 原型实现 | 状态 |
| --- | --- | --- |
| 主线视觉小说 + 选项影响好感 | `Story.gd` JSON 剧本引擎（背景 / 立绘 / 打字机 / 选项 / 剧情内战斗 / 自动 / 跳过 / 记录） | 第一章 4 节 + 第二章预告 |
| 亲密度 | 11 级好感（陌生 → 永恒），选项、短信、电话、瞬间都加好感，每级 +2% 战斗面板 | 完成 |
| 许愿 / 思念 | 5★ 1%、4★ 7%、60 抽软保底、70 硬保底、10 抽保 4★、限定 50% UP + 大保底、券优先 / 150 钻、重复转星屑 | 完成，2 万抽模拟验证 |
| 思念培养 | 升级（金币）、每人装备 2 张、思念故事 | 完成（芯核 / 星谱未做） |
| ARPG 战斗 | 轻量实时：点击攻击、技能冷却、预警闪避、共鸣槽联合技、搭档自动辅助 | 完成（建议加"自动 / 跳过"） |
| 日常陪伴 | 短信分支、电话（Lv.3 解锁）、瞬间点赞评论、七日签到、每日任务 | 完成（约会小游戏、拍照未做） |
| 商业化 | 月卡、礼包、钻石档位、通行证、星屑兑换 | 沙盒支付，正式版需接 Google Play Billing / StoreKit 验单 |
| 3D 写实美术 | 2D 立绘与卡面由 image 2（gpt-image-2）按 `assets/manifest.json` 批量生成，表情与卡面用参考图保持同一角色 | 流水线完成，当前为占位图 |

**差异化建议**：

1. 原创 IP"澜城 2049 · 深空潮汐局"，三位男主对应深海 / 星轨 / 余烬三种气质，避免霸总模板，每人都有"脆弱时刻"剧情。
2. 2D 高质量插画 + AI 生成动态思念（视频模型）替代昂贵的 3D 采集，包体控制在 1GB 内，这是对比头部最现实的成本优势。
3. 战斗保留但做"可自动 / 可跳过"，奖励不打折，照顾"来谈恋爱"的用户。
4. 留存靠日常陪伴（签到、任务、短信、电话、瞬间）而不是靠卡池；限定池半年一次，概率与保底全部公示。
5. 商业化从月卡和通行证起步，礼包用"一次性首充"与"周礼包"分层；避免涨价、货不对版这类信任事故。

## 6. 风险

- **合规**：国内上线需版号、抽卡概率公示、未成年人防沉迷；18+ 向内容在国内不可行，出海可分级。人脸 / 语音 / 生理期等个人数据不要采集。
- **信任**：卡池与宣传不符、定价变动、男主资源不均是近两年所有头部产品翻车的共同原因，需要内容审核与明确的产出承诺。
- **AIGC 美术**：跨表情、跨卡面的角色一致性靠参考图 + 固定提示词 + 人工筛选，仍需画师精修；玩家社群对 AI 作画敏感，上线前要决定是否声明。
- **字体与素材版权**：原型用文泉驿正黑（GPL 带字体例外），上架前换商用字体；BGM / 音效尚未接入。
- **竞争**：一超格局短期难改，但 3D 新品（Code Sol、夜幕之下）在路上；小团队应该专注一个男主线做到极致再扩展。
- **技术**：Godot 导出 Android / iOS 需本地导出模板与签名，内购与云存档需要服务端。
